# Glosario: de la palabra técnica a la palabra simple

Úsalo todo el tiempo. Los nombres propios (Cloudflare, Wrangler, Node, GitHub, Meta, GoHighLevel, Zapier, Make,
Hotmart) se dicen tal cual: la persona los va a buscar así en Google.

## Lo que NO dices → lo que SÍ dices

| NO digas | SÍ di |
|---|---|
| deploy, desplegar | publicar tu página en internet |
| Worker | tu página en Cloudflare (el programa que la atiende) |
| Wrangler, CLI | la herramienta de Cloudflare (después de explicarla una vez, «Wrangler») |
| terminal, consola | la ventana de comandos (Terminal en Mac, PowerShell en Windows) |
| API token | token de acceso: una llave que le das a tu compu para publicar en tu Cloudflare |
| secret, variable de entorno | valor secreto (se guarda aparte, nunca en la página) |
| D1, base de datos | tu base de registros: la lista de personas que llenaron el formulario |
| schema, migración | las tablas de tu base (dónde se guarda cada dato) |
| endpoint, `/api/lead` | la dirección que recibe el formulario |
| JSON, plan.json | el plan de tu página (un archivo con todos sus textos y su diseño) |
| render, build | armar la página |
| assets | los archivos de la página (letras, fotos) |
| dominio custom, custom domain | tu dominio propio (www.tumarca.com) |
| DNS | la guía telefónica de internet: dice a qué servidor va tu dominio |
| nameservers | los «administradores» de tu dominio (para pasarlo a Cloudflare) |
| SSL, certificado | el candado de seguridad (https) |
| workers.dev | tu dirección gratis de Cloudflare (algo como mi-pagina.tunombre.workers.dev) |
| webhook | un aviso automático: cada registro nuevo se manda a otra herramienta (GoHighLevel, Zapier, Make) |
| CAPI, API de conversiones | el aviso a Meta desde el servidor (mide mejor que el píxel solo) |
| UTM | las etiquetas del link del anuncio (dicen de qué campaña vino cada persona) |
| honeypot | un campo trampa para robots (la gente no lo ve) |
| rate limit | un freno para quien manda demasiados registros seguidos |
| localhost, vista previa local | la vista previa en tu compu (nadie más la ve) |
| CSV | un archivo que se abre con Excel o Google Sheets |
| npx, npm | el «instalador» que viene con Node: descarga lo que hace falta |
| Node.js | el motor que corre los programas de la skill en tu compu |
| repo, carpeta del proyecto | la carpeta de tu página |
| commit, push | guardar una versión / subirla (no hace falta para publicar) |
| error 401 / 403 | Cloudflare dice que no tienes permiso (el token no sirve o le falta un permiso) |
| error 404 | no existe esa dirección |
| error 5xx | falló algo del lado del servicio (no es tu culpa: se reintenta) |

## Palabras de la página

| palabra | qué es |
|---|---|
| plantilla | el diseño de la página (Clásica, Nácar, Penumbra, Voltaje, Prisma) |
| sección | cada bloque de la página (portada, beneficios, preguntas…) |
| portada | la primera pantalla: título, promesa y botón |
| botón principal | lo que quieres que haga la gente (registrarse, comprar, escribirte, agendar) |
| página de gracias | la que ve la persona justo después de registrarse |
| por completar | un dato que falta y que no inventamos: se ve marcado en la vista previa y no deja publicar |
| legales | la política de privacidad y los términos y condiciones (obligatorios si recibes datos) |
| píxel de Meta | el código que mide tus anuncios de Facebook e Instagram |
| registro / lead | una persona que llenó el formulario |
| conversión | de cada 100 visitas, cuántas se registran |
